A centralized, immutable event log REST API for backend systems. This service acts as the permanent system of record for events generated by upstream services like **PayFlow** and **Notification Queue**.

## 🚀 Overview (Work in Progress — 7 Day Build)

Currently under development. This standalone service ingests business events (e.g., `PAYMENT_FAILED`, `USER_REGISTERED`) and provides robust querying and aggregation capabilities. Built to be dependency-light, relying purely on Java and Postgres without external message brokers.

## ✨ Key Features

* **Append-Only Event Store**: Enforced at the service layer — update and delete operations are blocked; events can only be created and read.
* **Flexible Metadata**: Leverages PostgreSQL `JSONB` to efficiently store unstructured event payloads from upstream microservices.
* **REST-Driven**: Lightweight HTTP API for seamless integration with other system components.

## 🔌 API Endpoints (Built So Far)

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `POST` | `/api/events` | Ingests and validates a new audit event. |
| `GET` | `/api/events` | Retrieves logs with filtering (event type, source service, date range) and pagination. |
