A centralized, immutable event log REST API for backend systems. This service acts as the permanent system of record for events generated by upstream services like **PayFlow** and **Notification Queue**.

## 🚀 Overview (Work in Progress — 6 of 7 Days Complete)

This standalone service ingests business events (e.g., `PAYMENT_FAILED`, `USER_REGISTERED`) and provides robust querying, filtering, and time-windowed retrieval — all backed by PostgreSQL `JSONB` for flexible, schema-agnostic payloads. The service is fully containerized with Docker for one-command local setup.

## ✨ Key Features

* **Append-Only Event Store** — events are immutable once written; no update or delete operations are exposed.
* **Flexible Metadata** — PostgreSQL `JSONB` stores unstructured event payloads from any upstream microservice without a rigid schema.
* **Powerful Querying** — filter by `entityId`, `actor`, or `action`, and narrow results to a specific ISO-8601 time window.
* **Pagination & Sorting** — results are paginated by default and sorted newest-first, with standard metadata (`totalPages`, `totalElements`) in every response.
* **Containerized** — a multi-stage `Dockerfile` and `docker-compose.yml` spin up the service and PostgreSQL together, with healthchecks and persistent volumes.
* **REST-Driven** — lightweight HTTP API for seamless integration with other system components.

## 🔌 API Endpoints

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `POST` | `/api/events` | Validates and persists a new, immutable audit event. Returns `201 Created`. |
| `GET` | `/api/events` | Retrieves paginated logs, filterable by `entityId`, `actor`, `action`, and a `startDate`–`endDate` time window. |

### Example: Filtered query


GET /api/events?action=PAYMENT_FAILED&startDate=2026-08-01T00:00:00Z&endDate=2026-08-29T00:00:00Z&page=0&size=10

## 🗂️ Schema Highlights

The core `AuditEvent` entity is designed to be a trustworthy, permanent record:

* Auto-generated **UUID** primary keys
* Immutable, server-set **timestamps**
* `JSONB` metadata column for arbitrary structured payloads from any producer

## 🐳 Running Locally

```bash
docker compose up --build
```

This builds the Spring Boot app image, starts a PostgreSQL container with a healthcheck and persistent volume, and boots `audit-service` once the database is ready.
